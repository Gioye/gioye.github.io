Gioyeimg Format Documentation

Gioyeimg is an image format with 5 versions based on the bit depth:

1. 1-bit (Early Bitmap):
   - 1 BIT per pixel, 2 colors.
   - 1 byte = 8 pixels (very compact).
   - Header format: 01YYYYZZZZ (YYYY = width, ZZZZ = height).

2. 8-bit (Bitmap):
   - 1 byte per pixel, 256 colors.
   - Header format: 08YYYYZZZZ.

3. 16-bit (Compressed Bitmap):
   - 2 bytes per pixel, 256 colors.
   - First byte indicates how many times the pixel is repeated.
   - Header format: 16YYYYZZZZ.

4. 24-bit (True Color):
   - 3 bytes per pixel (RGB), no repetition byte.
   - Header format: 24YYYYZZZZ.

5. 32-bit (Compressed True Color):
   - 4 bytes per pixel (RGBA), with a repetition byte.
   - Header format: 32YYYYZZZZ.

Each bit-depth version supports a different way of representing pixel data. The converter supports all 5 versions for both conversion to Gioyeimg and back to a regular image.
